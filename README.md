# NIKHILMOTION

निखिल मोशन — a free web radio for 90s Hindi film music.

## Radio library

The fixed 12-song demo has been replaced with a **64-song 90s Hindi film rotation**. Songs are timestamped inside three long-form YouTube jukeboxes published by Tips Official. The browser shuffles the 64-song catalogue, jumps to the selected song timestamp, and advances automatically.

Sources:
- Tips Official — 90's Bollywood Songs Playlist (19 songs)
- Tips Official — Best Of 90s Hits Hindi Songs Collection (25 songs)
- Tips Official — 90's Evergreen Hindi Songs Jukebox (20 songs)

Audio is embedded from YouTube; this repository does not host or download music files.
